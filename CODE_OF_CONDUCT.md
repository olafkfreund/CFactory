# Code of Conduct

This project adopts the **Contributor Covenant, version 2.1**.

The full text is available at:
https://www.contributor-covenant.org/version/2/1/code_of_conduct/

A plain-text copy:
https://www.contributor-covenant.org/version/2/1/code_of_conduct/code_of_conduct.txt

## Reporting

CFactory is maintained by a single maintainer rather than a conduct team, so
say that plainly instead of implying a process that does not exist. To report
a violation:

- Contact the maintainer, [@olafkfreund](https://github.com/olafkfreund),
  directly on GitHub, or
- If the report also describes a security problem, follow
  [SECURITY.md](SECURITY.md) instead.

There is no anonymous or third-party-mediated channel today. If that matters
for your report, GitHub's own [platform abuse reporting](https://support.github.com/contact)
is independent of this repository's maintainer and can be used instead.

## Enforcement

Reports are reviewed privately. Outcomes may include a private warning,
temporary or permanent removal from project spaces, or reversal of
contributions, following the Enforcement Guidelines in the Contributor
Covenant.
