# Intent: /api/events requires a write-scoped key

## Problem

`POST /api/events` (and its alias `/api/events/completion`) is exempt from the
API-key middleware (`app.py` `_EXEMPT_PREFIXES`). Anyone who can reach the
backend can upsert a work item, broadcast it to every cockpit, and dispatch the
next queued sequence stage. Once #500 merges it is the only unauthenticated
write under `/api`.

The senders (AIFactory, PFactory, TFactory completion webhooks) post with no
`Authorization` header today, although each pod already holds `APP_API_TOKEN`,
which the #500 review found equals the cockpit key in CFactory's keystore.

Separately, `CFACTORY_API_DEV_OPEN` and `CFACTORY_MCP_DEV_OPEN` are pydantic
`bool` fields, so `1`, `yes`, `on`, `t` and `y` also open them.

## Proposed outcome

- `/api/events` checks for a WRITE-scoped key, under `CFACTORY_EVENTS_AUTH_MODE`:
  `warn` (default) accepts the event but logs and counts every call that fails
  the check; `enforce` rejects it with 401 (403 for a key without WRITE); any
  other value fails closed (behaves as `enforce`).
- All three senders send `Authorization: Bearer $APP_API_TOKEN`, only to the
  origin of their configured webhook URL, and never log the token.
- Only a case-insensitive `true` opens `CFACTORY_API_DEV_OPEN` /
  `CFACTORY_MCP_DEV_OPEN`.

This ships warn mode only. The flip to `enforce` is a later gitops change once
the logs show zero unauthenticated calls.

## Affected users and systems

- CFactory backend (`app.py`, `config.py`), its tests and env docs.
- AIFactory `apps/web-server/server/services/completion.py`, `outbox.py`.
- PFactory `apps/backend/agents/triager.py`, `apps/backend/plan/completion.py`.
- TFactory `apps/backend/agents/triager.py`, `apps/backend/agents/completion_outbox.py`.
- Local dev setups that set a DEV_OPEN flag to something other than `true`.

## Constraints

- Warn mode must not drop a single event: the senders deploy independently.
- Never log a key or token.
- The token must not ride to a host other than the configured webhook origin
  (the outbox stores the URL with each row).
- Dev-open keystore (no keys) stays open for `/api/events`, as today.

## Open questions

None. The decision (warn first, `APP_API_TOKEN`, PFactory#930's origin check)
is given in the task.
