# Intent: fix the CFactory findings from the 2026-11-23 UI test

## Problem

The browser test (Factory#3873, CFactory#576) found:

- The version always shows 0.1.0 (`cfactory/__init__.py:3`), so nobody can
  tell what is deployed.
- The "1 of 2 repositories are stale" banner names no repository.
- Done cards on the Planning board carry every control (status, priority,
  Plan/Code/Test/Run).
- Needs-you lists stale items with no age, dismiss or link to the gate.
- The pipeline strip shows failed counts with no path to the failures.

(The card project picker is CFactory#574, which is blocked on
AIFactory#2194 and CFactory#575, and is out of scope here.)

## Proposed outcome

- The version shown is the deployed build.
- The stale banner names the repos.
- Done cards are quiet.
- Needs-you items show their age and link to where to act.
- Failed counts in the strip open the failures.

## Affected users and systems

CFactory backend (version), frontend, and the image build workflow.

## Constraints

- Bug fixes only.
- No new action kinds. Dismissing reuses the existing needs-you action
  kinds or is a local hide.
- CFactory keeps its current look until the Phase C redesign.

## Open questions

None.
