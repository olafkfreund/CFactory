# Spec: zod 3 -> 4.6.6

## Design

Bump zod to ^4.6.6, refresh the lock with npm install --package-lock-only, then fix the zod 4 breaks in src/api.ts: single-argument z.record(X) becomes z.record(z.string(), X); fix any other compiler or test errors (.default semantics, error APIs, ZodError .errors -> .issues).

## Alternatives rejected

Trivy ignore entry: hides a HIGH CVE. Staying on 3.x: no fixed version exists.

## Risks

.default() on objects now short-circuits parsing in zod 4; tests cover the parsed shapes.

## Verification

npm run typecheck, npm run lint, npm test in apps/frontend-web.
