# Spec: CFactory UI test fixes

## Design

- **B5.**
  - `cfactory/__init__.py`: `__version__` is `os.environ.get("CFACTORY_VERSION") or "dev"`.
    There is no package metadata, since the source is copied onto
    `PYTHONPATH`.
  - The `Dockerfile` takes `ARG CFACTORY_VERSION=dev` and sets it as
    `ENV`.
  - `deploy.yml`'s production build and push step (`:99`) passes the same
    `sha-<short>` tag it pins in GitOps as the build arg.
  - The image smoke check asserts the baked value.
  - `BackendPill.tsx:16` shows the value as it is (no added `v`), and
    `ServicesView.tsx:144` stays unchanged.
- **B13.** `cards.ts:149-168`: both the all-stale and the mixed banner
  name the stale repos (`repo.project`), up to 3, then "+N". Tests cover
  both branches and four stale repos.
- **B14.** `PlanningBoard.tsx:112-124` opts into a `compact` prop on
  `CardBody` for the done column:
  - title, key and the done timestamp (`updated_at`), plus the status
    select;
  - no stage buttons and no priority arrows.

  The Backlog is unchanged. Choosing a non-done status brings the full
  card back.
- **B15 (CF).** `PipelineStrip.tsx:98-150`: the failure badge becomes its
  own button that opens Pipeline with the existing Failed chip selected
  (`Board.tsx:44-69`). The chip and the badge share one predicate (a stage
  has failed), so failed tasks in the Finished section or in another active
  column still show under Failed.
- **B16.** `NeedsYouView.tsx` and `needsYou.ts`:
  - each row shows its **last activity** age: the newest timeline event
    timestamp, else `WorkItem.updated_at`, else "unknown age";
  - rows with no activity for 7 days or more go under a collapsed "Older"
    group;
  - the existing **Open** drawer stays the primary action;
  - a direct upstream link appears only where a verified route exists: a
    PFactory plan session at `/p/<slug>` with a known `session_id`, and
    AIFactory or TFactory task ids;
  - stalled rows and rows with no target keep the drawer only;
  - Dismiss is a local per-user hide (localStorage) with "Show hidden".

## Alternatives rejected

A server-side dismiss for needs-you: it would be new state and a new
feature.

## Risks

- B14 must keep reopen possible.
- B16 age must not break when an item has no timestamp: show "unknown age".

## Verification

- vitest for B13, B14, B15 and B16.
- A backend test for B5's version resolution.
- CI.
- After release, a browser re-test:
  - Services shows the deployed version;
  - the banner names repos;
  - done cards are quiet;
  - Needs-you shows age and links, and Older is collapsed;
  - the strip's failed count opens the failures.
