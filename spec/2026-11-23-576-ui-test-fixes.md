# Spec: CFactory UI test fixes

## Design

- **B5.** `cfactory/__init__.py` reads `CFACTORY_VERSION`, else the
  package metadata version, else "dev". The image build passes the release
  tag or short sha as a build arg into that env var. `routes_health.py:19`,
  `ServicesView.tsx:144` and `BackendPill.tsx:16` show it unchanged.
- **B13.** `cards.ts:153-168`: the stale banner lists the stale repos'
  names (up to 3, then "+N"). Update the `cards.test.tsx:732` assertion.
- **B14.** `PlanningBoard.tsx:112-124`: for the done column, `onStage` is
  not passed and `onMutate` keeps only the status change, so a card can be
  reopened. `CardParts.tsx` renders done cards compact: title, key and
  timestamp, plus a status select.
- **B16.** `NeedsYouView.tsx` and `needsYou.ts`: each item shows its age
  (relative time from its timestamp) and an "Open" link to the gate:
  - the plan approval opens in PFactory;
  - the review opens in AIFactory or TFactory.

  Items older than 7 days are grouped under "Older" and collapsed. Dismiss
  is a local per-user hide (localStorage), restorable via "Show hidden".
- **B15 (CF part).** `PipelineStrip.tsx`: the failed count is a link to the
  Pipeline view filtered to failed items. Add that filter if it is missing.

## Alternatives rejected

A server-side dismiss for needs-you: it would be new state and a new
feature.

## Risks

- B14 must keep reopen possible.
- B16 age must not break when an item has no timestamp: show "unknown age".

## Verification

- vitest for B13, B14, B15 and B16.
- A backend test for B5's version resolution.
- CI.
- After release, a browser re-test:
  - Services shows the deployed version;
  - the banner names repos;
  - done cards are quiet;
  - Needs-you shows age and links, and Older is collapsed;
  - the strip's failed count opens the failures.
